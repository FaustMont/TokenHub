# Схема канонического bundle миграции

## Версия

В bundle используется SemVer для `schema_version`. CLI отклоняет несовпадающие мажорные версии.

## Массивы ресурсов

| Поле | Описание |
|------|----------|
| `providers` | Конфигурации провайдеров ИИ |
| `provider_resources` | Экземпляры ресурсов провайдеров |
| `models` | Определения моделей |
| `routes` | Правила маршрутизации, связывающие модели с провайдерами |
| `teams` | Ссылки на команды (только метаданные) |
| `projects` | Конфигурации проектов |
| `users` | Определения пользователей-администраторов |
| `api_keys` | Определения API-ключей (секреты через `$secretRef`) |
| `quota_policies` | Шаблоны политик квот |

## Ссылки на секреты

Для секретов используется формат `{"$secretRef": "ENV_NAME"}`. Sink разрешает их во время применения из:
- `env` — переменных окружения
- `file` — файла с секретами
- `prompt` — интерактивного ввода

## Предупреждения

Каждое предупреждение содержит:
- `severity`: `info`, `warn` или `blocker`
- `code`: машиночитаемый код
- `message`: понятное человеку описание
- `path`: опциональный путь к затронутому полю

## Стратегии идентификаторов (ID)

- `stable` — детерминированный на основе external_ref
- `prefixed` — префикс источника + хэш (по умолчанию)
- `source` — сохранение исходных ID
