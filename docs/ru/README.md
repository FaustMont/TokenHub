# Документация TokenHub

Язык: [English](../README.md) | [简体中文](../zh-CN/README.md) | [日本語](../ja/README.md) | Русский

Документация TokenHub организована вокруг трёх ролей, используемых в корпоративном управлении токенами (Token Governance). Язык документации по умолчанию — английский. Локализованные версии на русском, китайском и японском языках используют единый набор англоязычных скриншотов и демонстрационных данных.

## Архитектура и развёртывание

- [Архитектура](architecture.md): режимы развёртывания, плоскости управления и данных, поток запросов к моделям, персистентность и границы безопасности.
- [Развёртывание](deployment.md): Docker Compose, переменные окружения, базы данных, обратное проксирование и проверки работоспособности.
- [Эволюция базы данных](database-evolution.md): прямые миграции (forward-only), базовая линия внедрения, команды обслуживания и совместимость при откате.
- [Руководство по настройке PostgreSQL](postgresql-setup.md): конфигурация PostgreSQL, эксплуатация и миграция данных.
- [Бенчмаркинг производительности](performance-benchmarking.md): воспроизводимое сравнение шлюзов, внутренние бенчмарки аллокаций и бюджеты регрессий.

| Руководство | Аудитория | Основной рабочий процесс |

| [Подключение Codex к TokenHub: быстрый старт с профилем](codex-tokenhub-profile-quick-start.md) | Пользователи Codex, которым нужен только изолированный профиль | Создание профиля, установка ключа, проверка подключения и восстановление |

## Общие англоязычные демонстрационные данные

В примерах и скриншотах используется один набор данных, чтобы все языковые версии оставались визуально согласованными:

| Объект | Пример |
| --- | --- |
| Организация | Acme AI Platform |
| Команда | Platform Engineering |
| Проект | Payments Assistant |
| Центр затрат | AI Platform Cost Center |
| Модель | gpt-4.1-mini |
| Плейсхолдер API-ключа | YOUR_TOKENHUB_API_KEY |

## Рекомендуемый порядок чтения

1. Начните с руководства, соответствующего вашей роли.
2. Прочтите раздел «Концепции» на странице встроенной документации API для синхронизации терминологии.
3. Используйте примеры API в Руководстве пользователя для интеграции приложений.
4. Ознакомьтесь с Руководством администратора перед вводом в промышленную эксплуатацию.
